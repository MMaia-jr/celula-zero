# THESIS-ROUND-001 — Investigação estratégica independente

Status: PREREGISTRADA — NÃO EXECUTADA

Data de preregistro: 2026-08-15

Classe: Experimento de deliberação estratégica

## 1. Propósito

Investigar independentemente, por meio de múltiplos participantes externos de IA:

- o que a Célula Zero é atualmente;
- o que foi concretamente construído ou demonstrado;
- qual mecanismo central parece estar emergindo;
- o que o projeto poderia plausivelmente se tornar em seu potencial máximo.

Este é um experimento de deliberação estratégica.

Este experimento NÃO é:

- um teste de interoperabilidade;
- um processo de votação;
- uma tentativa de fabricar consenso;
- um processo de aprovação de protocolo;
- uma decisão sobre a identidade final do projeto.

## 2. Participantes planejados

Sessões externas de participantes planejadas:

- DeepSeek;
- Claude;
- Gemini;
- Grok;
- Kimi.

Mistral é intencionalmente adiado por indisponibilidade temporária de uso e poderá ser usado posteriormente como replicação independente direta via GitHub.

ChatGPT NÃO é participante cego independente nesta rodada, pois já produziu uma interpretação estratégica preliminar.

O papel posterior de ChatGPT será:

- auditoria;
- comparação;
- síntese;
- identificação de convergência e divergência;
- preparação de opções de decisão.

O fundador humano permanece como autoridade final de decisão.

## 3. Cegamento e independência

Cada participante externo deve trabalhar independentemente.

Nenhum participante poderá receber:

- a resposta de outro participante;
- a tese preliminar de ChatGPT;
- uma síntese de respostas anteriores;
- a interpretação do fundador sobre a resposta de outro participante.

Todas as respostas dos participantes devem ser coletadas antes de qualquer comparação cruzada.

## 4. Investigação comum

Todos os participantes devem responder às mesmas perguntas centrais:

1. O que é a Célula Zero hoje?
2. O que existe concretamente?
3. O que foi efetivamente demonstrado?
4. O que NÃO foi demonstrado?
5. Quais aprendizados importantes vieram de falhas e experimentos?
6. Qual é o núcleo irredutível se GitHub, fornecedores específicos de IA, JSON-LD, blockchain, DAO e as implementações técnicas atuais forem removidos?
7. “Protocolo dos Protocolos” é a abstração correta?
8. Qual papel o GRAPH-000 realmente desempenha?
9. Qual papel os humanos devem continuar desempenhando?
10. O que o INTEROP-001 realmente provou?
11. Que relação, se houver, existe entre “Da Invisibilidade à Evidência” e o “Protocolo dos Protocolos”?
12. Qual é o menor produto útil no mundo real?
13. O que o sistema poderia se tornar em:
    - curto prazo;
    - estágio maduro;
    - máximo potencial plausível?
14. Quais condições tornariam o projeto genuinamente importante?
15. Quais condições tornariam o projeto irrelevante ou falsificariam sua tese central?
16. Onde o projeto tem maior probabilidade de estar enganando a si mesmo?
17. Defina o projeto em:
    - uma frase conservadora baseada em evidências;
    - uma frase ambiciosa, mas defensável;
    - uma frase de visão de máximo potencial.
18. Qual é a única coisa mais importante que precisa ser demonstrada a seguir?

## 5. Rótulos epistêmicos obrigatórios

Os participantes devem distinguir:

- FACT;
- PROJECT CLAIM;
- INFERENCE;
- HYPOTHESIS;
- VISION;
- RECOMMENDATION.

## 6. Quadro adversarial comum

Para cada conclusão estratégica principal, identificar:

- benefício;
- pressuposto oculto;
- risco principal;
- explicação alternativa;
- teste mais barato;
- critério de rejeição.

## 10. Ausência de votação

A contagem de concordâncias não decide a tese.

Convergência é evidência apenas de estabilidade interpretativa.

Divergências devem ser analisadas por:

- evidência utilizada;
- pressupostos;
- poder explicativo;
- falsificabilidade.
