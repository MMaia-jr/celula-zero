## Proveniência relacional experimental

Nesta rodada, quando uma resposta surgiu de uma pergunta direta, a relação pergunta → resposta é preservada.

Pergunta e resposta continuam sendo Registros Originais independentes, com autores distintos.

A associação entre elas não constitui:

- interpretação;
- síntese;
- claim;
- consenso;
- decisão.

Esta organização está sendo testada empiricamente antes de qualquer alteração do protocolo.
