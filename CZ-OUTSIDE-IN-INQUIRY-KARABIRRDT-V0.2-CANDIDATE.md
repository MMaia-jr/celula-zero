## 0. What changed from v0.1

v0.2 preserves the Outside-In Inquiry while incorporating five corrections:

1. the metabolism is recursive/non-linear, not a one-way funnel;
2. `CONCERN ESCALATED` is a legitimate outcome;
3. ambiguous gaps default toward the least constructive viable classification:
   `ADOPT → MAP → COMPOSE → EXTEND`;
4. `EXTEND / MISSING` requires concrete observed property loss;
5. the first lived episode is time-bounded so episode-driven development does
   not become endless gap-driven construction.

It also reconciles the Inquiry with current canonical state:

- D037 remains the Genesis Readiness envelope;
- the current canonical state already targets observable Founder capacity;
- Candidate Interpretation and Discovery-context work are available primitives,
  not the whole lived metabolism;
- external transfer remains HOLD.

## 3. Capacity-delta lens

Do not create a universal score.

Ask qualitatively and with observable examples:

- What could the Human understand before and after?
- What could the Human decide before and after?
- What action became newly possible or materially easier?
- What relation/resource/tool became usable?
- What dependency disappeared?
- What dependency increased?
- What learning remained with the Human/Cell?
- What capacity existed only because infrastructure or an external assistant
  temporarily supplied it?
- What new possibilities appeared?

Candidate dimensions remain inquiry lenses:

`PERCEPTUAL / EPISTEMIC / COGNITIVE / AGENTIAL / RELATIONAL / MATERIAL / OPERATIONAL / REGENERATIVE`

## 4. Construction classifier

For every observed gap:

### ADOPT
Existing standard/process/tool already preserves the property.

### MAP
Existing CZ capability already represents the needed semantics sufficiently.

### COMPOSE
Existing capabilities work but must be connected for the episode.

### EXTEND
A concrete property is lost and the smallest extension is required.

### MISSING
No existing standard/process/capability can preserve the required property.

Tie-breaker:

`ADOPT → MAP → COMPOSE → EXTEND`

`MISSING` is not a convenience label.

For `EXTEND / MISSING`, answer before implementation:

> What exact real possibility or required property is lost if we do not create
> this?

Without a concrete answer:

`DO NOT BUILD`

## 5. Episode time-box

For the first Founder episode:

- one bounded existing-capability composition attempt;
- if blocked, identify exact property loss;
- at most one bounded repair attempt for that property loss;
- if the episode still cannot produce meaningful consequence or capacity
  readback, stop for Human Review.

Human Review options:

`CONTINUE`
`REVISE FRAMING`
`CHANGE EPISODE`
`RETURN TO READINESS COMPONENT`
`STOP / INQUIRY NOT USEFUL`

Do not repeat without repaired property loss, new evidence or new uncertainty.

# Founder Lived-Capacity MVP — candidate Definition of Done

A Founder episode may be considered complete for Human Review when:

1. one real concern enters in ordinary language;
2. the Original Record remains distinct from interpretation;
3. relevant context is recovered without Marcos manually reconstructing the
   whole project;
4. interpretation is attributed, source-linked and Human-correctable;
5. at least one useful possibility is discovered or `NO USEFUL DISCOVERY` is
   honestly observed;
6. the Human selects/rejects the direction;
7. existing capacities/resources are composed before new build;
8. one bounded real action occurs when the selected episode requires action;
9. a real result/consequence or legitimate inability to proceed is observed;
10. Human Decision remains Human;
11. capacity delta is described with observable examples;
12. `CONCERN ESCALATED / NO GAIN / PARTIAL / FAIL / INCONCLUSIVE` remain valid;
13. the episode can be reconstructed without collapsing
    `Record / Interpretation / Claim / Evidence / Verification / Decision`;
14. no hidden terminal/SQL/manual-message-bus dependency is silently treated as
    ordinary habitability;
15. no new architecture was introduced without exact property loss;
16. Marcos performs K15 Human Review.

This does not demonstrate external utility, adoption, PMF or scale.
