## Gate

Allowed result:

`PASS / FAIL / PARTIAL / INCONCLUSIVE`

### PASS

Only if the complete lived slice is observed:

`ENTRY → CONTEXT → ACTION → PRODUCTION / STATE CHANGE → CONSEQUENCE / CONTINUATION → RETURN`

and Marcos can simply use the experience without manually operating Huly or
reconstructing the technical system.

### PARTIAL

Use when meaningful portions work but the full vertical slice is not yet
habitable.

### FAIL

Use when the tested composition cannot preserve a required property or the
normal Human path cannot carry the slice.

### INCONCLUSIVE

Use when infrastructure or external conditions prevent a meaningful test of the
actual human/product question.

A technical test pass alone is not a PASS for this WP.

## Stop conditions

STOP and return to Human Review if:

- a Huly core patch appears necessary before the Human slice can even be tried;
- the proposed change expands into general Huly fork maintenance;
- the work starts implementing broad CZ architecture instead of the minimum
  lived slice;
- infrastructure repair becomes the principal output;
- the only usable path requires manual IDs, direct DB manipulation or a
  diagnostic harness;
- the experience becomes “use Huly and mentally translate it into CZ”;
- a new paid service or material recurring cost becomes necessary;
- authority or provenance cannot be preserved without changing the agreed scope;
- the environment cannot run the selected bounded substrate reliably enough to
  test the human episode.

In all such cases:

`STOP → OBSERVE PROPERTY LOSS / BLOCKER → HUMAN REVIEW`
