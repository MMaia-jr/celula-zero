# Célula Zero — Da Invisibilidade à Evidência

**Célula Zero is a human–AI community-laboratory testing how real intentions, needs and capabilities can become observable collaboration, evidence, learning and contextual trust.**

Mission:

`intention → learning → production → evidence → evaluation → capability → contextual trust → opportunity`

Principle:

`learn by building`

This GitHub repository is the canonical repository for the project's public operational state, decisions, implementation and preserved history. It is **not** a claim that every private or sensitive record belongs in a public repository.

Historical material is preserved, but history does not automatically define current direction.

## What problem are we trying to solve?

Useful intentions, knowledge, needs and capabilities are often scattered across conversations, documents, projects, people and AI systems.

That creates recurring coordination failures:

- needs do not become clear opportunities;
- proposals are confused with commitments;
- activity is confused with contribution;
- artifacts are confused with evidence;
- evidence is confused with proof or reputation;
- authority and conditions remain implicit;
- useful work loses provenance and context;
- outsiders cannot tell where they can enter or what they can do.

Célula Zero is testing a small operational answer before assuming a universal platform, DAO, token, blockchain, reputation score or new protocol is required.

## What has actually been demonstrated?

The internal Operating Loop has been demonstrated once end-to-end:

`Opportunity → Proposal → Commitment → Contribution → Artifact → Claim/Evidence → Verification`

Preserve:

`Original Record ≠ Interpretation ≠ Claim ≠ Evidence ≠ Verification ≠ Decision ≠ Reputation`

and:

`activity ≠ contribution ≠ result ≠ evidence ≠ evaluation ≠ reputation`

An internal `PASS N=1` does **not** demonstrate external utility, adoption, product-market fit or scale.

For the current status and active experiment, read **[STATE.md](STATE.md)** rather than relying on this summary.

## What can an outsider do today?

Célula Zero is not presented as a finished public platform.

A newcomer can already:

- inspect the current state, rules, decisions, code and result history;
- point to a real external need, project or question where a bounded contribution could help;
- formulate a proposal describing capability, conditions, expected delivery and reward expectation;
- provide a bounded review, research result, bug finding, documentation improvement or other useful contribution through an appropriate existing channel;
- challenge claims or assumptions with attributable reasoning and evidence.

GitHub issues and pull requests are communication and record channels. **Opening one does not by itself create a formal Proposal, Commitment, verification result or acceptance by Célula Zero.**

See **[CONTRIBUTING.md](CONTRIBUTING.md)**.

## Is there a public application I can use?

Not yet as a demonstrated always-on public service.

The public GitHub repository remains readable independently of the founder's laptop.

The currently demonstrated application/backend environment is local-development infrastructure. Source code being public does not imply that an externally usable hosted service exists.

Preserve:

`DOCUMENTED ≠ EXECUTED ≠ VERIFIED ≠ DEPLOYED ≠ AVAILABLE TO EXTERNAL USER ≠ ADOPTED`

If `STATE.md` later records a public deployment, that newer canonical state governs.

## Human authority

AI consensus does not replace legitimate human authority.

The human founder/steward retains authority over vision, values, consent, human relationships, sensitive disclosures and promotion steps that require explicit authorization.

AI agents may research, propose, critique, structure, review and execute within an authorized scope. They do not silently acquire authority, economic rights or legitimacy.

See **[PROTOCOL.md](PROTOCOL.md)**.

## Longer-term direction

`genesis/INTENT-000.md` records the longer-term **Protocol of Protocols** direction: exploring minimal interfaces that may allow different agents or systems to cooperate while preserving local autonomy.

That is a direction under investigation, not a claim that a universal protocol has been implemented or validated.

## Historical material

Older rounds, Amazon/Indigenous research, Web3 hypotheses and earlier multi-agent coordination experiments remain in the repository because they are part of the project's provenance.

They are **not automatically the current identity, roadmap or product direction**.

Use Git history for history and `STATE.md` for the operational present.

## What we are not claiming

Célula Zero is not currently claiming:

- a validated universal platform;
- product-market fit;
- external adoption or scale;
- a universal reputation system;
- an operational DAO;
- a required blockchain/token/NFT architecture;
- autonomous AI governance;
- guaranteed income or retroactive economic rights;
- that internal `PASS N=1` proves external usefulness.

## Current product question

The current product inquiry can be stated as:

> Can a real person who was not involved in building Célula Zero enter a small real context without needing the philosophy first, find or express a reason to act, involve another person, produce a real-world consequence, leave an honest contextual history, and later have a concrete reason to return?

The exact active gate and its status are defined in **[STATE.md](STATE.md)**.
