## Adopted target

Adopt `CZ vNext — Habitable MVP` as a continuous human experience:

`OPEN CZ → AUTHENTICATE → PROGRESSIVE ONBOARDING → RECOGNIZE PERSON / PROFILE / RELATIONS → ENTER CELL CÉLULA ZERO → CONVERSE NATURALLY → RECONSTRUCT CONTEXT → THINK / PLAN / ACT → HUMAN-CONFIRMED MATERIAL ACTION → DURABLE ATTRIBUTABLE STATE → CLOSE → RETURN → CONTINUE`

The MVP uses a conversation-first Home, persistent normalized threads and
messages, explicit server-compiled context, progressive resumable onboarding,
living Profile/presence, a working Célula Zero Cell surface, a minimal
provider-neutral Work projection where no reachable substrate satisfies the
need, structured authority-checked tools, useful Activity, and a useful or
hidden Discover surface.

Use Vercel AI SDK and assistant-ui if the current versions integrate cleanly
with the existing Next.js/React application. Use one low-cost model through an
authorized provider. Keep model/provider replaceable and the product identity
neutral; this Decision does not claim Essenthius is implemented.
