## Adopted direction

Adopt:

`LIVED CAPACITY EPISODES AS CRITICAL-PATH DRIVER`

Célula Zero passa a usar episódios reais de transformação de capacidade como
mecanismo primário para orientar o critical path.

O critério de avanço deixa de ser, por si só, completar componentes ou acumular
PASSes técnicos. O trabalho deve ser selecionado e ordenado pela tentativa de
fazer um episódio real circular por capacidades existentes e observar:

- se um Humano, relação, Project, Cell ou outro contexto legítimo se torna mais
  capaz;
- em que dimensão essa capacidade mudou;
- qual consequência real ocorreu;
- qual dependência permaneceu ou aumentou;
- qual propriedade concreta foi perdida quando o episódio não conseguiu
  prosseguir.

## Lived-capacity episode semantics

A lived-capacity episode begins from a real Human Dream, Need, concern,
decision, opportunity or blockage whose value is independent of testing
Célula Zero.

The episode may involve, when relevant:

`EXPRESS / ORIGINAL RECORD`
`→ PERCEIVE`
`→ DISCOVER`
`→ RELATE`
`→ COMPOSE CAPACITY`
`→ LEARN`
`→ CONDITIONS / AGREEMENT`
`→ ACT`
`→ RESULT / REAL CONSEQUENCE`
`→ EVIDENCE / VERIFICATION / HUMAN DECISION`
`→ CELEBRATE / REGENERATE`
`→ UPDATED CAPACITY / NEW POSSIBILITIES`

This is not a mandatory linear funnel.

A Result may legitimately return the episode to an earlier stage, reveal that
the concern was deeper than expected, or produce:

`CAPACITY GAIN / NO MATERIAL GAIN / CONCERN ESCALATED / WRONG FRAMING / INSUFFICIENT CONTEXT / INCONCLUSIVE`

No outcome is upgraded merely to make the cycle appear successful.

## Time-box / anti-drift rule

A lived episode must not become an unlimited justification for horizontal
construction.

For the first Founder episode, prefer:

1. one bounded composition attempt using existing capability;
2. at most one bounded repair of a concrete observed property loss;
3. then Human Review if the episode still cannot reach a meaningful consequence
   or capacity-delta readback.

Human Review may choose:

`CONTINUE / REVISE / RETURN TO READINESS COMPONENT / CHANGE EPISODE / STOP`

Do not repeat the same test without repaired property loss, new evidence or a
new uncertainty.
