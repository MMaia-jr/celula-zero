## Memory direction

D051 does not adopt a new memory platform.

The working memory principle is:

> Memory is the capability to reconstruct relevant state from durable,
> attributable records under legitimate authority.

Therefore:

`MODEL MEMORY ≠ ESSENTHIUS MEMORY`

`CHAT HISTORY ≠ ESSENTHIUS MEMORY`

`CONTEXT PACK ≠ ESSENTHIUS MEMORY`

A context pack or context window is a **compiled projection** of legitimate
state for a bounded task. It is not itself the institutional memory.

Existing Git, Supabase, Dragon Dreaming records, Human Direction, AI execution
provenance, Result Packages, Room/context portability and other current CZ
capabilities must be inspected and composed before any new RAG, graph, memory
service, vector database or orchestration layer is considered.

## Centralization / distribution direction

Célula Zero does not pursue total decentralization as an end in itself.

It centralizes where coherent identity, continuity or understandable experience
requires centrality.

It distributes authority, control and failure domains where doing so preserves
a concrete property such as autonomy, resilience, security, legitimate
authority, ownership, continuity or provider independence.

It prefers federated, portable and auditable infrastructure where appropriate.

## Decentralized technology remains available

D051 does **not** reject blockchain, DID, Verifiable Credentials, attestations,
content addressing, smart accounts, DAO, NFT, SBT or related technologies.

It also does **not** adopt them as mandatory architecture.

For each candidate technology, preserve the current construction rule:

`READBACK → ADOPT → MAP → COMPOSE → EXTEND`

Use the technology when a lived episode or explicit requirement demonstrates a
property that existing standards/processes/infrastructure cannot preserve
adequately without it.

Historical D. Esentya / Essenthius material may inform lineage and research but
does not silently become current Célula Zero architecture, tokenomics,
reputation, governance or economic policy.

Preserve:

`HISTORICAL LINEAGE ≠ CURRENT ARCHITECTURE`

`PRESERVED ≠ CURRENT`
